Vector Requirements

Let vector<L, T> be shorthand for a vector of length L and with elements of type T.


[C] Vector Construction

[C.1] Vector construction from list

A vector<L, T1> may be constructed from a list of values of length L and type T2 if:
    - T1 = T2, or
    - T2 is convertible to T1.

[C.2] Vector construction from vector

A vector<L, T1> may be constructed from a vector<L, T2> if:
    - T1 = T2, or
    - T2 is convertible to T1.

[C.3] Vector construction from scalar

A vector<L, T1> may be constructed from a single value x of type T2 if:
    - T1 = T2, or
    - T2 is convertible to T1.

Each element of the resulting vector has the value x, after applying any necessary conversions.

[C.4] Vector construction from matrix

A vector<L, T1> may be constructed from a matrix<L, 1, T2> or matrix<1, L, T2> if:
    - T1 == T2, or
    - T2 is convertible to T1.


[DA] Data Access

[DA.1] Vector element access

The first element of a vector can be read from and written to using the subscript 0, the second element of a
vector can be read from and written to using the subscript 1, and so on.

[DA.2] Vector assignment

A vector<L, T1> can be assigned to another vector<L, T2> if:
    - T1 = T2, or
    - T2 is convertible to T1.

After the assignment, each element in the first vector has the value of the corresponding element in the second vector
after applying any necessary conversions.

[DA.3] Vector scalar assignment

A vector<L, T1> v can be assigned to a scalar value x of type T2 if:
    - T1 = T2, or
    - T2 is convertible to T1.

After the assignment, each element of v is equal to x, after applying any necessary conversions.

[DA.4] Vector matrix assignment

A vector<L, T1> may be assigned to a matrix<L, 1, T1> or matrix<1, L, T1> if:
    - T1 = T2, or
    - T2 is convertible to T1.


[DL] Data Layout

[DL.1] Size of a vector

If s is the size of the type T in bytes, then the size of a vector<L, T> is L * s bytes.

[DL.2] Vector data layout

The elements of a vector are laid out in memory contiguously, with vector<L, T>[0] being stored at the first
address allocated to the vector, vector<L, T>[1] being stored at the second, and so on.


[CMP] Comparison

[CMP.1] Vector comparison

A vector<L, T1> v1 is considered equal to a vector<L, T2> v2 if for i in [0, L), v1[i] = v2[i].


[A] Arithmetic

[A.1] Vector addition

Let v1 be a vector<L, T1> and v2 be a vector <L, T2>.

The result of the expression v1 + v2 is a vector<L, T3> v3, where:
    - T3 is the type of the value of the expression x + y, where x is of type T1 and y is of type T2, and
    - For i in [0, L), v3[i] = v1[i] + v2[i].

[A.2] Vector scalar addition

Let v be a vector<L, T1> v1 and x be a scalar value of type T2.

The result of the expression v + x is a vector<L, T3> v2, where:
    - T3 is the type of the value of the expression a + b, where a is of type T1 and b is of type T2, and
    - For i in [0, L), v2[i] = v1[i] + x

[A.3] Vector subtraction

Let v1 be a vector<L, T1> and v2 be a vector <L, T2>.

The result of the expression v1 - v2 is a vector<L, T3> v3, where:
    - T3 is the type of the value of the expression x - y, where x is of type T1 and y is of type T2,
    - For i in [0, L), v3[i] = v1[i] - v2[i].

[A.4] Vector scalar subtraction

Let v1 be a vector<L, T1> and x be a scalar value of type T2.

The result of the expression v - x is a vector<L, T3> v2, where:
    - T3 is the type of the value of the expression a - b, where a is of type T1 and b is of type T2, and
    - For i in [0, L), v2[i] = v1[i] - x

[A.5] Vector scalar multiplication

Let v1 be a vector<L, T1> and x be a scalar value of type T2.

The result of the expression v * x is a vector<L, T3> v2, where:
    - T3 is the type of the value of the expression a * b, where a is of type T1 and b is of type T2, and
    - For i in [0, L), v2[i] = v1[i] * x

[A.6] Vector scalar division

Let v1 be a vector<L, T1> and x be a scalar value of type T2.

The result of the expression v / x is a vector<L, T3> v2, where:
    - T3 is the type of the value of the expression a / b, where a is of type T1 and b is of type T2, and
    - For i in [0, L), v2[i] = v1[i] / x


[S] Special Operations

[S.1] Vector magnitude

Let v be a vector<L, T1>, where T1 is an integral or floating-point value.

The expression v.mag() yields a scalar value x of type T2 representing the magnitude of v. The type T2 is the type
returned by the standard library square root function when called on an operand of type T1.

[S.2] Vector normalization

Let v be a vector<L, T1>, where T1 is an integral or floating-point value which is not a zero vector.

The expression v.norm() yields a vector<L, T2> representing the result of normalizing the vector v. The type T2 is the
type of the value of the expression T1 / v.mag().

If v is a zero vector, then the expression v.norm() returns a zero vector of length L.

[S.3] Vector dot product

Let v1 be a vector<L, T1> and v2 be a vector<L, T2>.

The expression v1.dot(v2) yields a scalar value x of type T2 representing the inner product of vectors v1 and v2. The
type T2 is the type of the expression T1 * T2.

[S.4] Vector cross product

Let v1 be a vector<3, T1> and v2 be a vector<3, T2>.

The expression v1.cross(v2) yields a vector<3, T3> representing the cross product of v1 and v2. The type T3 is the type
of the value of the expression T1 * T2.

[S.5] Vector test against zero

Let v be a vector<L, T>.

The expression v.zero() yields a boolean value that is true when all elements of v are equal to the default value of T
and false otherwise.
